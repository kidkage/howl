Color tokens

The Howl accent stays exactly #c524ff. Mode changes are semantic role tokens; the original slate, white reading surface, near-black copy, muted metadata, pale dividers, and soft avatar tints remain in the palette.

Named role tokens: page, surface, surface-muted, primary/secondary text, link, accent, borders, controls, and focus.

WCAG AA contrast check

Measured with the WCAG 2.x sRGB relative-luminance formula. Text uses 4.5:1, large text and non-text UI use 3:1. Select the theme toggle to remeasure the live mode.

Initial failures and fixes: The exact Howl violet is preserved as the accent fill and large wordmark. For small text, a darker same-hue violet is used in light mode and a lighter same-hue violet in dark mode; dark violet ink is used on accent-filled controls.
