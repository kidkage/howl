# Howl home screen exploration

Open `/explorations/04-home-screen/` in the repository's Vite development server. This phone-first layout uses the shared tokens from `../03-design-system/tokens.css`; it is a separate exploration and does not change the live app or previous rounds.

At phone widths the page contains the Howl name, a write-post composer, separated story cards, and a bottom tab bar. Tablet widths (640–959px) use the left navigation with events below the feed; laptop widths (960px and up) place navigation left, the feed in a comfortable 640px column, and upcoming events at the right. The empty state is rendered when the sample post list is empty.

The controls are visual layout samples only; no posting, navigation, or event RSVP behavior is implemented.

The page follows the device's light or dark color-scheme preference. Campus event cards are illustrative examples, not current listings.
